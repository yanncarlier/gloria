# Word Fingerprint App

A minimal Flutter/Android app that records a few spoken takes of the same
word and compares them using:

1. Pure-Dart MFCC extraction (`lib/dsp/mfcc.dart`, `lib/dsp/fft.dart`)
2. DTW (Dynamic Time Warping) distance for the actual same/different decision
   (`lib/dsp/fingerprint.dart`)
3. A SimHash-style 128-bit fuzzy audio fingerprint (`lib/dsp/fingerprint.dart`)
4. A SHA-256 cryptographic proof of that fingerprint (`lib/dsp/fingerprint.dart`)

## Setup

This folder only contains the app-specific source files, not a full Flutter
scaffold (no `android/gradle`, `android/build.gradle`, `ios/`, etc. — those
are generated by the Flutter tool itself). To get a runnable project:

```bash
# 1. Scaffold a fresh Flutter project
flutter create word_fingerprint_app
cd word_fingerprint_app

# 2. Copy the contents of this archive's pubspec.yaml and lib/ over the
#    generated ones, and merge the <uses-permission> line from this
#    archive's AndroidManifest.xml into the generated one.

# 3. Install dependencies
flutter pub get

# 4. Run on a connected Android device or emulator
flutter run
```

## Notes

- Thresholds (`_dtwSameWordThreshold`, `_hammingSameWordThreshold` in
  `lib/main.dart`) are starting points copied from the reference Python
  implementation — tune them against a few real recordings on your target
  phone's microphone.
- Requires `minSdkVersion` >= 21 in `android/app/build.gradle` (Flutter's
  default template usually already satisfies this).
- All processing happens on-device; nothing is uploaded anywhere.
